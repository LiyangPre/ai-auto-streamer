# Moonlit terrace

`moonlit-terrace.png` is the local, opaque background (1672 × 941, approximately 2.5 MB). It was created with the built-in image generation tool; no external image URL or video is used at runtime. The original generated image remains in the Codex generated-images directory.

The browser covers the viewport with this painting, then draws cached drifting clouds or bounded rain strokes behind the character. Weather is capped at 20fps and DPR 1.25; it pauses in hidden tabs. Reduced-motion preferences, still mode, zero weather intensity and transparent backgrounds disable weather animation.

The scene library also includes `royal-palace.png` and `rose-garden.png`, plus transparent `deepseek-bow.png` and `claude-bow.png` static companions. Their final prompts and provenance are in [ADDITIONAL-ART.md](ADDITIONAL-ART.md). The palace pairs with at most 40 golden motes; all effects share the same animation budget. Companions follow the character's framing, with no independent animation. A masked CSS backdrop filter softens only the bottom 23% of the output; strength is adjustable from 0–12px. Transparent output hides all scene decorations and blur.

Beautiful polished anime environment painting, refined fine linework and softly painted gradients; silver-lavender, muted blue, dusty lilac, subtle warm lantern light. Background should feel calm, airy, elegant, cozy, with good mid-tone contrast for a silver-white character. No people, no characters, no animals, no text, logos, watermark, UI, or borders.
