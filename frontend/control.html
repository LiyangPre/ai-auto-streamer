STUDIO GUIDE

Your first little broadcast

  1. 发送模拟弹幕，检查回复和角色动作。Mock 是离线演示；真实 AI 请在 config.yaml 配置云端 API 或 Ollama。
  2. 2D Lite 是默认低算力模式。3D VRM 可在预览中切换；修改 config.yaml 可设置正式输出。
  3. 点击 Copy OBS source，将地址添加到 OBS 浏览器源，建议 1440 × 1080（4:3）。Scene 面板可设置宫殿、花园、月光背景、小伙伴、底部柔焦或透明输出。
  4. 预览默认静音。点击 Sound off 可开启；浏览器可能需要一次点击才能播放。
