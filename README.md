# AI Auto Streamer · Astra Studio

面向低本地算力的 AI 虚拟主播：接收直播弹幕，生成简短回复，以角色音色播报，并在浏览器中显示形象、表情和口型。日常直播使用云端文本/TTS 与轻量本地动画；整曲变声是独立的离线准备任务，计算量和准备时间更高。

默认角色是银龙 **Astra**。当前包含 **Chat / Songs / Stories** 三个模块。场景、DeepSeek 与 Claude 小伙伴、音乐和字幕设置共用；身份、回复风格、声音及各模块的表演方式按角色保存。

## 启动控制台与 HTML 输出

已安装的工作区：双击 **Start Studio.cmd**，保持终端运行。启动器打开控制台和输出页；已有服务时复用它。

```powershell
cd 'D:\ai auto streamer'
.\.venv\Scripts\python.exe -X utf8 scripts\start_studio.py
```

- 控制台：[http://127.0.0.1:8000/control](http://127.0.0.1:8000/control)
- HTML 输出 / OBS 或 Bilibili 浏览器源：[http://127.0.0.1:8000/?overlay=1&controls=0](http://127.0.0.1:8000/?overlay=1&controls=0)
- 动作测试：[http://127.0.0.1:8000/rig-preview](http://127.0.0.1:8000/rig-preview)

输出画布为 **4:3 / 1440 × 1080**，浏览器源与推流画布应使用相同尺寸。普通浏览器首次点击输出页解锁声音；控制台预览默认静音，避免重复收音。用 **Ctrl+C** 停止终端中的服务器。关闭网页不会停止服务，不能直接双击 HTML 文件代替服务器。

首次安装可使用 Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 scripts\start_studio.py
```

前端附带已构建的运行文件。修改前端依赖时再执行 `npm ci`、`npm run build:expressions` 或 `npm run build:vrm`。下载、分离、变声和歌词识别使用独立的可选环境，见歌曲流程文档；日常播放不加载这些模型。

## 文本与声音

控制台打开 **API connections · 接口设置**，填写文本/TTS 的 API Key、Base URL 和模型，先测试再保存。实际讲话使用的 TTS 在当前角色的 **Voice** 面板选择并试听。空密钥输入保留原配置，页面不回填保存过的密钥。也可使用本地 `.env`；真实密钥不应写入 YAML 或 Git。

YAML 中的文本默认顺序：

```text
glm-4.7-flash → glm-4-flash-250414 → glm-4-flashx-250414
→ glm-4-air-250414 → glm-4.5-air → glm-4.7-flashx
```

支持关闭思考的 GLM 请求明确禁用 thinking；旧的普通 GLM-4 没有思考模式。临时错误、限流、空回复和超时可切到下一模型，认证、证书和内容审核失败停止请求。默认每模型首文本等待 3 秒、整条回复共用 20 秒预算、失败模型冷却 90 秒。已输出文本后不拼接另一模型回复。备用链可能包含付费型号，实际账号权限与费用由服务商决定。

当前声音默认使用 **`mimo-v2.5-tts-voicedesign`**，由当前角色保存的 **Voice description** 设计音色。聊天、试听和故事使用同一描述，表演提示放在故事文本内。该型号的兼容流接口需要等待整段推理完成，不能把流式参数当作低首包延迟保证。故事、歌曲和常用过渡语优先预先准备、缓存。也可选择 Edge、GLM-TTS 或 MiniMax，控制台按接口能力显示参数。

MiMo 的 Base URL 和密钥应来自同一账号控制台。**Direct / Auto / Environment** 比较网络路径，不更改 VPN。连接失败先查看 DNS、代理、TLS、超时或 HTTP 分类；一个 `APIConnectionError` 不能说明密钥被封禁。

## 角色与共用舞台

**Current character** 切换档案，**＋ New character** 复制档案；服务器每次启动选择 Astra。Identity、Replies、Voice、Actions 和模块设置按角色保存，**Apply & save** 后同步输出。

| 按角色保存 | 所有角色共用 |
|---|---|
| 身份、称呼读法、回复风格、音色、暖场台词 | 场景库、构图、字幕、音乐与小伙伴 |
| 各模块的姿态、表情强度、场景预设 | API 连接与本机私有密钥 |
| 歌库、点歌策略、禁播列表、故事触发与互动意愿设置 | 本地 PNG 背景与 MP3 音乐素材库 |

`data/character-profiles.json` 是角色与共用舞台的主要存储，旧 `studio-settings.json` 是兼容导出。`.env` 和忽略提交的 `data/.env.api-studio-settings.json` 保存凭证。YAML 提供基础配置，保存过的角色/API 设置覆盖对应项。

共用场景默认是银龙座驾，带慢速循环窗景和可关闭的轻微震动；另有宫殿、花园、月光露台、透明背景和本地 PNG。支持角色位置/大小、底部柔焦、天气及小伙伴开关。音乐可使用内置曲目、本地 MP3，或由用户授权捕获的音乐标签页/应用；讲话时自动降低 BGM 音量。

切换场景时先显示过渡画面，等新背景、人物和需要的小伙伴素材解码就绪，再显示新场景。加载失败保留旧场景并提供重试；快速连续切换只采用最后一次请求。场景变化可配一句简短的角色过渡语，开关在 **Modules · 模块 → Interaction settings · 互动与转场设置**。视觉加载不重置歌曲、歌词或故事的播放时钟。

角色身份与画稿分开绑定。目前安装的完整画稿包是 Astra；复制档案不会自动生成另一角色的脸、关节或坐姿。

## 基础表情与自然动作

情绪表情、自然眨眼、轻微呼吸、真实音频驱动的口型和受限动作属于基础需求，按各画稿的安全范围执行。在各模块 **Pose & face · 姿态表情** 设置表情、开关、强度、身体动作幅度和场景预设。关闭情绪表情仍保留眨眼、口型。本地连续混合不增加一次表情规划 API 调用。

站姿只开放待机、点头、思考、害羞、轻笑、轻迎等受限小动作。肩肘、头部有角度边界，切换保持运动连续，手腕、手掌和接触点保持连接。驾驶画稿增加约 4.8 秒一轮的局部躯干呼吸，最大抬升约 5.5 个原图像素；面部、双手、方向盘、座位、安全带固定点和仪表台小伙伴保持原画位置。页面隐藏、关闭呼吸或启用减少动态效果时停止身体呼吸。

唱歌房采用持麦坐姿，上半身连贯呼吸、随录音轻摆，握麦手和麦克风始终相连；眼睑按画稿倾角闭合，情绪通过眉眼、嘴角与腮红区分。保留 DeepSeek、Claude 玩偶，歌曲结束恢复 Chat 对应场景。可打开[静音动作与表情预览](http://127.0.0.1:8000/static/previews/singing-motion.html)检查，无需播放歌曲。

口型跟随正在播放的人声包络；有独立人声轨时优先使用它，背景音乐不接入口型。停止、暂停和缓冲时闭嘴。这是音节节奏近似，不是逐音素识别；普通 PNG 不会自动获得任意动作。更换服装/画稿需要校准关节、面部及接触点。

## 三个模块

### Chat · 聊天

接收 Bilibili 或控制台测试消息，按有界窗口选择弹幕，生成短答，经本地审核后送字幕/TTS。原样朗读弹幕默认关闭，启用后与回答统一审核。支持观众记忆、礼物合并感谢、SC 正文优先回答、分批欢迎、安静时暖场和慢回复的缓存等待台词。

当前 Bilibili 接入是 `blivedm` 网页消息协议，支持可选 `BILIBILI_SESSDATA`；官方 Open Live 仍需单独接入。匿名 UID=0 使用临时标识且不写个人记忆，同名/打码昵称仍不能可靠区分。礼物/SC 使用有界队列和可见失败计数，不是支付送达保证。项目不替用户开播、发送弹幕或购买礼物。

### Songs · 歌曲

优先使用完整录音或离线变声后的录音：

```text
下载/上传 → 确认版本与音色 → 分离人声/伴奏 → 离线变声
→ 保持原时长混音 → 听检 → 入库/备份 → 匹配 LRC → 点歌/播放
```

完整命令、环境、文件和验收标准见 [requirement_song.md](requirement_song.md)。上一批五首及 2026-10-28 新增的 **I Really Want to Stay at Your House、海屿你（新录音）、泡沫** 均已完成 50 步转换并入库。重复标题先备份再替换，不自动播放。**告白气球、海屿你、大鱼** 的禁播继续保留；准备新版或添加歌词不解除禁播。**起风了、小幸运、泡沫、I Really Want to Stay at Your House** 已保存匹配后的默认歌词，《海屿你》《大鱼》已附加用户提供的定时歌词。音频、参考音色及模型不随 Git 下载，应另行备份。

支持上传整曲 MP3、可选人声口型轨、LRC 与歌词偏移。歌词跟随实际录音位置，暂停/恢复不另起计时，保存后下次播放自动载入。点歌命令例如 `点歌 起风了`、`点歌《小幸运》`，只匹配当前角色已完成且允许播放的歌曲；可配置队列、冷却、重复间隔和禁播列表。

**Duration · 演唱时长** 默认“完整唱完”。取消勾选后可输入开始/结束时间（秒数或 `分:秒`），或用试听当前位置标记区间，再“保存演唱区间”。结束留空则唱到结尾。每首歌独立保存，手动播放和观众点歌都会使用；修改只影响下一次演唱。区间试听可在本机先检查，正式演唱时歌词与口型仍跟随原曲位置，结束后自动回聊天。

演唱暂停普通聊天/暖场和进场欢迎。完整混音可暂停共用 BGM；单独人声可配伴奏。歌曲结束回到 Chat，可播放缓存的随机收尾语。Voice Design 不提供唱歌；另保留的实验 MiMo 小曲不保证指定旋律和准确音高。离线变声保留音源旋律与节奏，不修正源录音唱错的音。

### Stories · 故事

十个原创日常小喜剧仅有 **Astra、Claude、DeepSeek** 三位室友。以当前角色声音预先生成后，可随机、指定或通过“讲个故事”等弹幕触发；随机袋减少重复，安静房间自动触发可选开启。

准备需要 TTS，播放已准备故事不调用 LLM/TTS。更改文本或声音后需重新准备对应片段。欢迎音频就绪后，故事暂停、欢迎一批观众，再从原位置继续；唱歌不被欢迎打断。完成或停止有限表演均回到 Chat。

## 观众意愿与自然切换

明确的 `点歌 起风了`、`讲个故事` 仍走原有命令入口，不必等投票；是否接受和何时开始仍服从当前角色歌库、禁播、队列、冷却与舞台状态。普通聊天还可以识别“想听你唱歌”“讲讲你们家的趣事”等意愿，分别累计唱歌、故事请求。

在 **Modules · 模块 → Interaction settings · 互动与转场设置** 可开关语义互动、场景过渡语，调整下列设置并保存到当前角色；面板同时显示当前请求计数与选歌状态。

| 默认设置 | 行为 |
|---|---|
| 120 秒内累计 6 次 | 达到同一模块的可信、肯定且当前有效的请求数后，准备进入对应互动 |
| 同一观众间隔 20 秒 | 限制重复刷请求；消息去重另行执行 |
| 触发后冷却 300 秒 | 避免聊天与节目频繁来回切换 |
| 征集歌名 90 秒 | 唱歌意愿达标后先问“想听什么歌”；超时未选到可播放歌曲则继续聊天 |

选歌期间直接发歌名也可被识别。未学会的歌曲会得到“这首我还没学会”的回应，禁播歌曲则说明暂时不唱；不会临时下载、生成或解除禁播。故事只从当前声音已经准备好的片段中选择。正在播放的歌曲不会被这些请求打断。

模型返回的短台词与隐藏的意愿建议分开解析，只有审核后的台词进入字幕和 TTS。服务器校验建议格式、来源消息、置信度和角色策略，决定是否计数或执行。否定、引用、历史消息不应计票；识别仍可能有误，可关闭语义互动并保留明确命令。临时票数与选歌状态不跨服务重启保存，模型失败也不会直接切换节目。

普通聊天与选歌使用**一次模型调用、两条逻辑输出**：JSON 的 `reply` 是可播台词，`intents` 是给 Python 的隐藏建议。选歌时先核对本地歌库和队列，再使用同一回复中的台词；若台词与实际结果不符，就使用受控短句，不再额外调用模型生成第二遍确认。换场、征集歌名等独立事件仍可以生成各自的短过渡语。JSON 校验在模型回退链内进行，格式错误可切换下一个模型；所有模型仍关闭思考。

## 架构与数据

`src/modules/` 注册模块服务、路由、控制台和输出适配器。`StageActivity` / `PerformanceSession` 管理舞台占用、结束确认、超时兜底和恢复；`performance-output.js` 共用录音时钟、字幕、口型及中断处理。新模块通过源码注册安装，不从浏览器执行任意插件。

```text
src/                   配置、角色、弹幕、LLM/TTS、安全与模块服务
frontend/              控制台、HTML 输出及轻量动画
scripts/               启动、下载、分离、变声、导入与歌词工具
tests/                 Python 与前端 Node 测试
data/songs/            入库录音和元数据（忽略提交）
data/song-sources/     下载源与下载清单（忽略提交）
data/songs-converted/  分离、转换任务、混音和进度（忽略提交）
data/lyrics/           参考/匹配 LRC、识别缓存和报告（忽略提交）
data/stories/          按声音签名缓存的故事（忽略提交）
```

默认只监听 `127.0.0.1`。控制接口校验本地 Host、Origin 与 `X-Studio-API: 1`，WebSocket 校验本地 Origin。观众昵称、弹幕和记忆属于不可信输入，不进入 system 指令。完整短答先审核再发字幕/TTS，审核错误阻止输出。本地规则无外部往返，但不能识别所有语境与谐音，详细边界见架构和基础需求。

## 测试与排查

离线视觉测试无需 API Key：

```powershell
.\.venv\Scripts\python.exe -X utf8 main.py --config config.local-test.yaml
```

打开 [http://127.0.0.1:8001/control](http://127.0.0.1:8001/control)。该配置使用 Mock 并关闭 TTS。自动测试：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
npm test
```

本次改动的定向回归：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest tests.test_audience_intents tests.test_interaction_routes -v
node --test tests/test_car.cjs tests/test_car_drive.cjs tests/test_scene_transition.cjs tests/test_interaction_controls.cjs
```

运行服务后可打开[静音车内预览](http://127.0.0.1:8000/?preview=1&overlay=1&muted=1&scene=car)查看呼吸，或[独立场景切换演练](http://127.0.0.1:8000/static/previews/scene-transition.html)检查加载、连续切换、失败重试。后者不连接直播输出、不播放音频；使用离线测试服务时将链接端口改为 `8001`。

| 问题 | 检查位置 |
|---|---|
| 控制台打不开 | 终端是否运行、端口是否占用；使用 HTTP 地址 |
| 回复失败 | API connections、实际模型/备用链、网络路径与错误分类 |
| 无声音/重复声音 | 先试听并解锁输出音频；检查静音和直播姬音量表，保留一个收音路径 |
| 故事音色不对 | 保存 Voice description 后重新准备，旧录音不会自动变声 |
| 歌曲口型被伴奏带动 | 上传同起点的人声口型轨 |
| 歌词越来越偏 | 使用相同录音版本做时间匹配；固定 offset 只能修正整体偏移 |
| 变声慢/中断 | 查看准备状态并复用已验证分块；更多 worker 不一定更快 |
| 更新后仍是旧画面 | 刷新控制台及 Bilibili 浏览器源；服务端代码更新后重启 Studio |

## 第三方组件

项目使用 FastAPI、blivedm、Edge-TTS、Three.js/three-vrm 及可选 Live2D 渲染。表情适配层使用固定版本的 SoulLink emotion engine，并保留许可。离线歌曲工具使用独立的下载、分离、转换和识别组件。依赖与素材分别遵循各自许可，详见依赖清单与对应流程文档。
